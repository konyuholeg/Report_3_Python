# 📑 Звіт про проєкт «Internship Tracker»

---

## 1. Мета та завдання проєкту

Метою проєкту є створення простої, мінімалістичної та ефективної вебсистеми для студентів, яка дозволяє організувати процес працевлаштування та пошуку IT-стажувань.

### Основні завдання:
1. Зберігання вакансій та стажувань (наприклад: *EPAM — QA Trainee, SoftServe — Python Internship*).
2. Відстеження воронки відбору за 6 статусами:
   $$\text{"Знайдено"} \longrightarrow \text{"Подано заявку"} \longrightarrow \text{"Зацікавило"} \text{ або } \text{"Відмова"}$$
3. Збір базової статистики та розрахунок успішності (**рівень зацікавленості**).
4. Фіксація нагадувань про дату інтерв'ю чи дедлайн.
5. Завантаження стажувань із зовнішнього API в базу даних.
6. **AI-аналіз відповідності**: автоматичне порівняння вимог вакансії (наприклад: *Python, SQL, REST*) зі списком навичок студента.

---

## 2. Технологічний стек

* **Бекенд:** Python 3.13, Django 6.1, MySQL 8.4 LTS.
* **Фронтенд:** Vanilla HTML5, Vanilla CSS3 (мінімалістичний світлий дизайн без зайвих бібліотек), чистий JavaScript.

---

## 3. Архітектура та структура бази даних

Проєкт реалізовано за архітектурою **MVT (Model-View-Template)**.

### 3.1. Моделі даних (`tracker/models.py`)

1. **`StudentProfile` (Профіль студента)**:
   - `full_name` — ім'я кандидата.
   - `skills` — список навичок через кому (наприклад: `Python, SQL, REST`).
   - Метод `get_skills_list()` — повертає нормалізований список навичок.

2. **`Internship` (Вакансія / Стажування)**:
   - `company` — назва компанії (*SoftServe, EPAM, Genesis*).
   - `position` — позиція (*Python Internship, QA Trainee*).
   - `status` — поточний статус (`found`, `applied`, `offer`, `rejected`).
   - `required_skills` — вимоги до вакансії (*Python, SQL, REST*).
   - `reminder_date`, `reminder_text` — дата і нотатка нагадування.
   - `url` — посилання на вакансію.
   - Метод `ai_match(profile)` — алгоритм зіставлення вимог із профілем.

---

## 4. Алгоритм AI-порівняння навичок

Алгоритм виконує порівняння множини вимог вакансії $R$ із навичками студента $U$:

$$S = \frac{|R \cap U|}{|R|} \times 100\%$$
